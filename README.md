# task-manager
Node.js + Supabase 智能任务管理系统

## ✨ 功能清单
- 添加任务，支持高/中/低优先级
- 任务列表展示标题、优先级、完成状态
- 切换「完成/未完成」状态，已完成任务带删除线
- 删除任务
- 按优先级筛选：全部 / 高 / 中 / 低
- 任务默认按创建时间倒序排列

## 🗄️ Supabase 建表 SQL
在 Supabase SQL 编辑器执行：
```sql
create table tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text check (priority in ('高','中','低')),
  completed boolean default false,
  created_at timestamptz default now()
);

alter table tasks enable row level security;
create policy allow_anon_select on tasks for select using (true);
create policy allow_anon_insert on tasks for insert with check (true);
create policy allow_anon_update on tasks for update using (true);
create policy allow_anon_delete on tasks for delete using (true);
